# Hotel Gran Marques — Sistema de Gestión Hotelera

Proyecto frontend funcional en HTML, CSS y JavaScript vanilla, construido a partir del prototipo de la evidencia GA5-220501095-AA1-EV03.

## Estructura

- `index.html`: estructura de las pantallas y componentes.
- `css/styles.css`: estilos responsivos y sistema visual.
- `js/app.js`: navegación, login, modales, datos demo y lógica de interacción.

## Cómo ejecutar

1. Descarga la carpeta completa.
2. Abre `index.html` en un navegador moderno.
3. Usa uno de estos accesos de demostración:
   - Recepción: `recepcion` / `123456`
   - Administración: `admin` / `123456`

No requiere servidor, librerías externas ni instalación de dependencias.

## Funcionalidades incluidas

- Inicio de sesión con roles de demostración.
- Dashboard con indicadores y accesos rápidos.
- Gestión de reservas con creación, consulta y cancelación.
- Gestión de habitaciones con creación y edición.
- Servicios adicionales.
- Facturación y registro de pagos.
- Reportes con indicadores de ocupación.
- Mantenimiento y alertas.
- Configuración básica.
- Persistencia local con `localStorage`.
- Diseño responsive para escritorio, tableta y móvil.
- Mapa de navegación equivalente al flujo del prototipo: Login → Dashboard → módulos principales → retorno al Dashboard.
